## 2. 三方对照摘要

### 2.1 写入表现

| 指标         | Go（2026-08-29） | Node PoC（2026-08-29） | **正式 Node（本轮）** |
| ------------ | ---------------- | ---------------------- | --------------------- |
| 发送 / 成功  | 5391 / 5391      | 5392 / 5392            | **5395 / 5395**       |
| 成功率       | 100%             | 100%                   | **100%**              |
| 实际 RPS     | 29.6             | 29.6                   | **29.6**              |
| 约写入事件数 | 215,640          | 215,680                | **215,800**           |
| 延迟 p50     | 3.73 ms          | 1.25 ms                | **3.10 ms**           |
| 延迟 p95     | 5.07 ms          | 1.73 ms                | **4.38 ms**           |
| 延迟 p99     | 11.67 ms         | 6.43 ms                | **12.00 ms**          |
| 延迟 max     | 18.09 ms         | 15.34 ms               | **15.48 ms**          |

正式 Node 延迟接近 **完整 Go**，略慢于「仅写入」PoC（符合预期：正式版含鉴权、限流、presence 管线、聚合等）。

### 2.2 内存 / CPU（压测采样）

| 指标             | Go             | Node PoC | **正式 Node**            |
| ---------------- | -------------- | -------- | ------------------------ |
| 压测前 RSS（约） | ~20 MB（空闲） | ~54 MB   | **~66 MB**（切流后空闲） |
| 压测中 RSS 均值  | ~54 MB         | ~67 MB   | **~109 MB**（112056 KB） |
| 压测中 RSS 峰值  | ~62 MB         | ~68 MB   | **~119 MB**（121720 KB） |
| 压测中 CPU 均值  | ~10.4%         | ~2.5%    | **~8.7%**                |
| 压测中 CPU 峰值  | ~13%           | ~6.5%    | **~16%**                 |

相对 1.7GiB 机器：正式 Node 峰值 RSS **约 119MB**，仍远低于 300MB 验收线；CPU 均值约 9%，低于 50% 线。

### 2.3 验收对照

| 验收项   | 标准       | 正式 Node          |
| -------- | ---------- | ------------------ |
| 成功率   | ≥ 99.9%    | **通过（100%）**   |
| p95 延迟 | &lt; 200ms | **通过（4.4ms）**  |
| RSS 峰值 | &lt; 300MB | **通过（~119MB）** |
| CPU 均值 | &lt; 50%   | **通过（~8.7%）**  |

## 3. 结论

1. **生产已切到正式 Node Track**，健康检查正常；压测数据已清理，限流已恢复。
2. **同强度写入下正式 Node 全部达标**；延迟与 CPU 接近完整 Go，RSS 高于 PoC/Go 但余量充足。
3. PoC 报告中「完整实现 RSS 可能升到 150–250MB」的预估与本轮 **~119MB 峰值**一致偏乐观侧，仍可接受。
4. **性能侧支持维持 Node 作为现行实现**；后续重点是观察窗（真实 App JWT 流量、BFF 查询、presence 回写）而非再怀疑写入能力。

## 4. 局限

- 仍为本机 loopback；不含公网 TLS/Nginx。
- 未压管理端查询。
- 压测临时抬高限流；默认 IP 300/min 下达不到本强度（与 Go 现网一致）。
