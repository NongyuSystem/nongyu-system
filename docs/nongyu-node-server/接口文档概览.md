## 1. 背景与目标

### 1.1 背景

`nongyu-node-server` 为农屿单体业务后端，同时服务：

- `nongyu-rn-app`（学生端）
- `nongyu-web-admin`（管理端）

本服务**不校验教务密码**：学生端在 RN 内完成教务登录与个人信息抓取后，再调用 Node 完成「登录即注册 / 签发 Token」。管理端使用农屿管理员密码鉴权。

### 1.2 目标

- 统一双端鉴权、用户档案与设置同步
- 支撑广场（公告 / 反馈墙 / 大院）与阅读覆盖率
- 支撑 App 版本检查与管理端版本发布
- 支撑管理端用户管理与数据大屏（本库指标 + Track 指标 BFF）

### 1.3 非目标（本版不提供）

| 范围                      | 说明                                            |
| ------------------------- | ----------------------------------------------- |
| 埋点原始事件存储 / 日聚合 | 归 `nongyu-go-track-server`；管理端经 §6.6 读取 |
| 课表 CRUD                 | 课表领域表后置                                  |
| 教务 / 二课业务代理       | 客户端直连或后续单独接口集                      |
| Agent 会话                | 不落本库                                        |
| 管理员登录日志落库        | `loginType` 仅请求语义，不落库                  |

## 2. 通用约定

### 2.1 Base URL 与路径

- 业务前缀：`/api`
- 学生端：`/api/app/...`
- 管理端：`/api/admin/...`
- 内部：`/api/internal/...`（仅 Track 等内网服务，见 §7）
- 探活：`GET /health`（无 `/api` 前缀）
- Content-Type：`application/json; charset=utf-8`
- 时间字段：响应均为 **ISO-8601 UTC**（如 `2026-08-12T01:00:00.000Z`）
- JSON 字段：**camelCase**（库表 snake_case 由服务端映射）
- 响应头：每个请求回写 `x-request-id`（可主动传入同名请求头）

### 2.2 统一响应包

```ts
type ApiResponse<T> = {
  code: number; // 0 = 成功；非 0 = 业务/校验错误
  message: string;
  data: T | null;
};
```

成功：`{ "code": 0, "message": "ok", "data": ... }`  
失败：`{ "code": <非0>, "message": "...", "data": null }`

### 2.3 HTTP 状态码（已固定）

业务失败**不**用 HTTP 200 承载；一律按下列状态码 + `code`：

| HTTP | 场景                                                  |
| ---- | ----------------------------------------------------- |
| 200  | 成功（`code === 0`）                                  |
| 400  | 参数校验失败（`40001`）；登录限流亦返回本形态         |
| 401  | 未认证 / Token 无效 / 过期 / 作废（`40101`–`40104`）  |
| 403  | 无权限 / 账号禁用 / 管理员密码错误（`40301`–`40303`） |
| 404  | 资源不存在（`40401`–`40403`）                         |
| 502  | Track 指标代理失败（`50201`）                         |
| 503  | Track 不可达（`50301`）                               |
| 500  | 未捕获服务端错误（`50000`）                           |

### 2.4 业务错误码

| code  | 含义                                                      |
| ----- | --------------------------------------------------------- |
| 0     | 成功                                                      |
| 40001 | 参数校验失败（含学号格式、非法 gender、限流文案等）       |
| 40101 | 未认证（缺少/非法 `Authorization`）                       |
| 40102 | Token 无效（签名错误、载荷残缺、类型错误等）              |
| 40103 | Token 已过期（`exp`）                                     |
| 40104 | Token 已作废（顶号、登出、设备不符、用户不存在等）        |
| 40301 | 账号已禁用                                                |
| 40302 | 需要管理员权限 / 无权操作（含学生删非本人帖、超管未建档） |
| 40303 | 管理员密码错误                                            |
| 40401 | 用户不存在                                                |
| 40402 | 帖子不存在                                                |
| 40403 | 版本记录不存在                                            |
| 40404 | 管理员回复不存在（反馈墙未回复或已删）                    |
| 40405 | 留言不存在                                                |
| 40002 | 该帖子不允许留言（非大院帖）                              |
| 40304 | 无权删除该留言（非留言作者）                              |
| 40901 | 该反馈帖已存在管理员回复（一对一）                        |
| 50201 | 埋点指标查询失败（Track `ok: false` 或非预期响应）        |
| 50301 | 埋点服务暂不可用（超时、连接失败、5xx、Token 拒绝）       |
| 50000 | 服务器内部错误                                            |

### 2.5 鉴权

```http
Authorization: Bearer <jwt>
```

#### App JWT

- Claims：`uid`、`studentNo`、`tokenVersion`、`typ: "app"`、`deviceId`
- 校验：签名有效；`typ === "app"`；`users.status === 1`；`users.token_version === tokenVersion`；若 `users.current_device_id` 非空，则须等于 `deviceId`
- **同 `deviceId` 再次登录**：不 bump `token_version`（旧票仍可用）；**换设备**或库中设备为空后绑定新设备：`token_version += 1` 并更新设备字段
- 新用户首次登录：`token_version` 初始为 `1`
- 登出：`token_version += 1`，`is_online = 0`
- 默认 TTL：环境变量 `JWT_APP_TTL`（默认 `60d`）
- 超管学号（默认 `202308596`，见 `SUPER_ADMIN_STUDENT_NO`）App 登录时强制 `role=2`

#### Admin JWT

- Claims：`uid`、`studentNo`、`role: 1|2`、`typ: "admin"`；超管未建档时另含 `bootstrap: true` 且 `uid: 0`
- 校验：签名有效；`typ === "admin"`；bootstrap 票校验超管学号且不查库；否则 `users.role IN (1,2)` 且 `status === 1`
- **不设 `exp`（永不过期）**；**不踢号**（不依赖 `token_version`）
- 超管密码：`SUPER_ADMIN_DEFAULT_PASSWORD` 与 `admin_password_hash` **双轨命中**；无 `users` 行时仅默认密码，且**不写业务表**
- bootstrap 票仅可用于 `/api/admin/auth/me|logout|password`（改密无库时 403）；其它 `/api/admin/**` 返回 40302
- 自助改密：`PUT /api/admin/auth/password`

#### 内部 Token（Track 回写）

```http
X-Internal-Token: <INTERNAL_TOKEN>
```

- 环境变量 `INTERNAL_TOKEN`（≥16 字符），与 Track 的 `NODE_INTERNAL_TOKEN` 部署时对齐
- 常量时间比较；错误或缺失返回 HTTP 401，`code: 40101`

### 2.6 登录限流

`POST /api/app/auth/login` 与 `POST /api/admin/auth/login`：每 IP **15 分钟最多 60 次**。超限返回 HTTP 400，`code: 40001`，`message: 登录尝试过于频繁，请稍后再试`。

### 2.7 分页

| 参数       | 类型   | 默认 | 说明                       |
| ---------- | ------ | ---- | -------------------------- |
| `page`     | number | 1    | 从 1 开始                  |
| `pageSize` | number | 20   | 最大 **100**（超出按 100） |

```ts
type PageResult<T> = {
  list: T[];
  total: number;
  page: number;
  pageSize: number;
};
```

### 2.8 枚举与映射

| 字段                  | 值                                                              |
| --------------------- | --------------------------------------------------------------- |
| `gender`              | `0` 未知 / `1` 男 / `2` 女                                      |
| `role`                | `0` 普通用户 / `1` 管理员                                       |
| `status`              | `1` 正常 / `0` 禁用                                             |
| `postType`            | `announcement` / `feedback` / `courtyard`                       |
| `loginType`           | `browser` / `in_app`                                            |
| `platform`            | `ios` / `android` / `all`（版本检查 Query 仅 `ios`\|`android`） |
| `releaseChannel`      | `silent_ota` / `native`                                         |
| `theme`               | `sicau_green` / `sakura_pink` / `dark` / `system`               |
| `courseCardColorMode` | `distinct` / `unified`                                          |

**App 登录 `gender` 入参**：允许 `0|1|2` 或 `"0"|"1"|"2"|"男"|"女"|"未知"`。  
未传 / `null` / `""` → 落库 `0`。  
其它非法值 → **400 + 40001**（`gender 无效`），不会静默落 0。

**帖子 `subtype`**：实现侧校验为非空字符串、`≤32`；**不强制**文档历史上的枚举名单（`system`/`feedback`/`bug` 等由客户端约定即可）。

## 3. 核心业务流程

### 3.1 App 登录即注册

```text
RN 教务校验通过并抓取档案
  → POST /api/app/auth/login（档案 + 设备信息；不传教务密码）
  → 无用户则 INSERT + 默认 user_settings；有则刷新档案/设备（同设备不 bump tokenVersion；换设备则 bump）
  → 签发 App JWT
```

- 未知字段（如 `role` / `status` / `adminPassword`）会被忽略（Zod strip）
- `qq`：库中已有非空值则**不覆盖**；库空时可用请求体写入
- 新用户同时创建默认 `user_settings` 行
- 超管学号登录时强制 `role=1`

### 3.2 管理端登录

```text
POST /api/admin/auth/login（studentNo + adminPassword [+ loginType]）
  → 超管学号：默认密码或哈希双轨；无 users 行则 bootstrap 票（不写表）
  → 非超管：用户不存在 40401；role 非 1|2 → 40302；status !== 1 → 40301；密码不匹配 → 40303
  → 签发 Admin JWT（无 exp）；loginType 仅回显
```

### 3.3 广场阅读量

打开 `GET /api/app/posts/:id` 成功时（事务）：

1. `posts.view_count += 1`
2. 若 `(post_id, user_id)` 首次写入 `post_reads`：再 `unique_reader_count += 1`
3. 覆盖率（管理端）= `unique_reader_count / COUNT(users)`

App 列表/详情**不返回**阅读量；「我的帖子」返回 `viewCount`。

### 5.4 广场

```ts
type PostListItem = {
  id: number;
  postType: "announcement" | "feedback" | "courtyard";
  subtype: string;
  title: string;
  contentPreview: string; // 去 HTML 标签后截断约 120 字
  publishedAt: string;
  authorDisplayName?: string | null; // App 端恒为 null（反馈墙/大院对用户匿名）；署名仅 Admin 接口返回
};

type PostDetail = {
  id: number;
  postType: "announcement" | "feedback" | "courtyard";
  subtype: string;
  title: string;
  content: string;
  publishedAt: string;
  authorDisplayName?: string | null; // 同上，恒为 null
  isMine: boolean; // 仅供本人删帖；不向其他用户暴露作者身份
  // 反馈墙：管理员单条回复（用户侧统一「管理员回复」，无作者信息）
  adminReply?: { content: string; publishedAt: string } | null;
  // 大院：顶层留言列表（完全匿名，仅 isMine 自识）
  comments?: Array<{
    id: number;
    content: string;
    publishedAt: string;
    isMine: boolean;
  }>;
};

// 「我的帖子」列表项额外字段（普通广场列表不返回）
type MyPostListItemExtra = {
  replyCount: number; // 未软删回复总数（含 admin_reply 与 comment）
  hasReply: boolean; // replyCount > 0
};

// 轮询「我的新回复」单项
type NewPostReply = {
  replyId: number;
  postId: number;
  postType: "announcement" | "feedback" | "courtyard";
  postTitle: string;
  kind: "admin_reply" | "comment";
  content: string;
  createdAt: string;
};
```

#### `GET /api/app/posts`

**鉴权**：App JWT  
**Query**：`postType`（必填）、`page`/`pageSize`、`subtype?`（精确）、`keyword?`（可选，见下）  
排序：`publishedAt DESC`  
**成功 `data`**：`PageResult<PostListItem>`

**`keyword`（广场搜索）**：

- 未传 / 空白（trim 后空）：行为与无关键词列表一致
- 有值：trim 后长度 **1–64**；对 `title`、`content` 做转义后的 `LIKE %kw%`（两字段 OR），再与 `postType` / `subtype` **AND**
- 非法长度 → HTTP 400，`code: 40001`
- 软删帖永不返回；不跨分类（`postType` 仍必填）
- 规格：`docs/nongyu-node-server/specs/广场帖子搜索.md`

#### `GET /api/app/posts/announcements/latest`

**鉴权**：App JWT  
**成功 `data`**：`{ id, title, subtype, publishedAt } | null`

#### `GET /api/app/posts/:id`

**鉴权**：App JWT  
成功打开即计阅读（§3.3）；**不返回** `viewCount` / `uniqueReaderCount`  
**成功 `data`**：`PostDetail`，并按 `postType` 附加：

- `feedback`：`adminReply`（无则 `null`）
- `courtyard`：`comments`（按 `publishedAt ASC`，软删剔除）
- `announcement`：均不附加

#### `POST /api/app/posts/:id/comments`

**鉴权**：App JWT  
**约束**：仅 `postType=courtyard` 的帖子可留言；非大院帖 → HTTP 400，`code: 40002`，`message: 该帖子不允许留言`  
**请求体**：

| 字段      | 必填 | 说明              |
| --------- | ---- | ----------------- |
| `content` | 是   | trim 后 1–1000 字 |

**成功 `data`**：`{ id: number, content: string, publishedAt: string, isMine: true }`

#### `DELETE /api/app/posts/:id/comments/:commentId`

**鉴权**：App JWT  
仅留言作者本人可删；非作者 → HTTP 403，`code: 40304`，`message: 无权删除该留言`  
**成功 `data`**：`null`

#### `POST /api/app/posts`

**鉴权**：App JWT  
**请求体**：

| 字段       | 必填 | 说明                         |
| ---------- | ---- | ---------------------------- |
| `postType` | 是   | 仅 `feedback` \| `courtyard` |
| `subtype`  | 是   | 1–32 字符                    |
| `title`    | 是   | 1–200                        |
| `content`  | 是   | 非空                         |

**成功 `data`**：`{ id: number }`  
**副作用**：`postType=feedback` 且服务端已配置 `GITHUB_TOKEN` + `GITHUB_REPO` 时，**异步**在目标仓库创建一条 Issue（标题 `[反馈墙] {title}`，正文含帖子 ID / 分区 / subtype / 内容全文，label 取 `GITHUB_ISSUE_LABEL`）。该操作为 best-effort：失败仅记服务端日志，不影响本接口返回，也不回滚帖子。仅新增 Issue，帖子被删不会删除该 Issue。详见 `specs/反馈墙同步GitHub Issue.md`。

#### `DELETE /api/app/posts/:id`

**鉴权**：App JWT  
作者软删自己的 `feedback`/`courtyard`。  
非作者或公告 → HTTP 403，`code: 40302`，`message: 无权删除该帖子`  
**成功 `data`**：`null`

#### `GET /api/app/users/me/posts`

**鉴权**：App JWT  
**Query**：`page`/`pageSize`；可选 `postType=feedback|courtyard`（不传则两类都查，不含公告）  
**成功 `data`**：`PageResult<PostListItem & { viewCount: number } & MyPostListItemExtra>`

#### `GET /api/app/users/me/post-replies/new`

**鉴权**：App JWT  
轮询当前登录用户**自己帖子**下尚未通知的新回复（含管理员回复与用户留言）。  
**成功 `data`**：`NewPostReply[]`（按 `createdAt ASC`，最多 50 条）  
**副作用**：返回项的 `notified_author` 置 1；后续轮询不再返回。  
**说明**：不返回他人帖子下的回复；帖子被软删后其回复不再返回。

#### `GET /api/app/users/me/post-replies/received`

**鉴权**：App JWT  
当前用户作为**帖主**收到的回复 / 留言 inbox（排除自己留在自己帖下的）。

**Query**：`page?`、`pageSize?`（默认 1 / 20）

**成功 `data`**：`PageResult<MyPostReplyListItem>`

```ts
type MyPostReplyListItem = {
  replyId: number;
  postId: number;
  postType: "feedback" | "courtyard";
  postTitle: string;
  kind: "admin_reply" | "comment";
  content: string;
  publishedAt: string; // ISO UTC
};
```

**过滤**：回复与帖均未软删；`r.author_user_id ≠ 当前用户`；按 `publishedAt DESC`。不返回作者字段。

#### `GET /api/app/users/me/post-replies/sent`

**鉴权**：App JWT  
当前用户对**他人大院帖**发出的留言。

**Query**：同 received。

### 6.6 数据大屏（Track 指标代理）

> 管理端 **禁止** 直连 Track。Node 使用 `TRACK_BASE_URL`（默认 `http://127.0.0.1:8082`）与 `INTERNAL_TOKEN`（`X-Internal-Token`，对齐 Track `INTERNAL_TOKEN`）转发。

> Track 不可达 / 5xx / 403：HTTP 503，`code=50301`。其它上游失败：HTTP 502，`code=50201`。

### App

## 9. 与实现相关的对接注意

1. **App 每次登录都会使旧 App JWT 失效**（含同设备重登），客户端须始终使用最新 `token`。
2. 业务错误看 **HTTP 状态 + `code`**，不要假设失败也是 200。
3. 管理端升管理员：先 `PATCH role=1`，再 `PUT .../admin-password`（密码 ≥8）。
4. 版本 `DELETE` = 下架，记录仍在列表中（`isPublished=false`）。
5. 大屏「今日」按 `BUSINESS_TZ`（默认上海）日历日统计。
6. 大屏 DAU/页面/性能/崩溃走 `/api/admin/track/*`，须配置 `TRACK_BASE_URL` 且 Token 与 Track 一致。
