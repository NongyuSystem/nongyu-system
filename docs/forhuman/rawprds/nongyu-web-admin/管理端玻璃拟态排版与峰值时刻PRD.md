# 管理端玻璃拟态排版与峰值时刻 PRD

> 来源：2026-09-16 需求对齐会话。业务需求。  
> 状态：已实现。

## 背景

Web 管理端已对齐学院派暖绿与 PageFrame 信息层级，但材质偏「实心白卡」，扫读仍偏平。数据大屏「今日最高同时在线」只有人数，看不到今天哪个时间点同时在线最多。本期演进视觉（克制毛玻璃）并补峰值时刻。

## 目标

1. 管理端整体高级简约，浅底毛玻璃（苹果设置页那种干净玻璃，不是深色 Liquid Glass）。
2. 排版更符合扫读：大屏按「此刻 → 体量 → 趋势 → 用户是谁 → 行为 → 健康」分层；壳层与 CRUD 表面统一材质。
3. 「今日最高同时在线」KPI 显示**首次达到该峰值**的业务时区时刻，文案形如 `今日 14:32 达到`。

## 非目标

- 智慧助手对话内部 UI（消息列表 / 输入条 / 工具卡）
- 深色模式、换品牌绿、换字体、侧栏改成悬浮岛
- 趋势图按小时展示；历史日峰值时刻进趋势 hover（上线前无数据）
- 改采样周期、presence 超时、RN 上报
- 独立技术方案文档

## 需求类型

业务

## Grill 共识

| 项   | 结论                                                               |
| ---- | ------------------------------------------------------------------ |
| 归类 | 业务                                                               |
| 视觉 | 演进 MASTER：贴边壳 + 品牌绿 + 克制毛玻璃；不重写为 Tahoe 深色玻璃 |
| 范围 | 登录、壳层、工作台、大屏、CRUD 页表面；助手内部不动                |
| 排版 | 全站表面统一，大屏信息架构优先                                     |
| 峰值 | 首次达到；KPI 辅文 `今日 HH:mm 达到`；仅今日 KPI，趋势仍按天       |
| 文档 | 本 PRD + Spec；跳过独立 tech                                       |
