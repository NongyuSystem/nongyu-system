# 农屿项目文档管理策略（Agent需严格遵守）

- forhuman（为人类用户专开的文档库，Agent禁止将其加载进上下文，避免浪费Token）
- common（通用文档库，存放全局核心规则和一些全局的PRD或技术选型文档；含 `BugLog.md`：每次 Bug 修复必须追加根因与修复方法）
- nongyu-go-track-server（存放该项目的spec文档，除特殊需求和场景外，只能且必须存放spec文档，若用户有额外要求，可存放相应的技术文档）
- nongyu-node-server（同上）
- nongyu-node-track-server（同上）
- nongyu-rn-app（同上）
- nongyu-web-admin（同上）
- nongyu-website（同上）

**说明：**
forhuman目录为人类用户读写的文档库，用于记录用户手写的原始需求、技术选型草案以及开发计划和心得体会等等，文档的风格不一定符合规范且文档的时效性无法得到保证，Agent不应该主动将其加载进上下文避免浪费Token以及造成无关信息的上下文污染，除非用户显式要求Agent以其中的某些文档为参考

**敏感文档（禁止版本控制）：**

- 含数据库口令、SSH 口令/私钥路径明细、云账号等的本机文件必须列入根目录 `.gitignore`
- 现约定示例：`docs/nongyu-node-server/数据库连接信息.md`、`docs/nongyu-node-server/服务器连接信息.md`、`docs/nongyu-go-track-server/服务器连接信息.md`、`scripts/ops/`
- 仓库内只提交对应 `*.example.md` / `*.env.example` 模板；真实值仅存在开发者本机
