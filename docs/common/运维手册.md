## 2. 发布操作手册（怎么发）

### 2.1 Web 四端（自动）

1. 本机过 husky 门禁（oxlint/oxfmt/commitlint）→ push `origin/main`
2. CD 按路径自动构建+SSH 部署+健康检查回滚（详见 `GitHub持续交付.md`）
3. 手动补发：Actions → CD → Run workflow → 选 `all/site/admin/node/track`
4. 🔲 验证方式：push 一个 docs 提交确认不误发；dispatch `site` 确认链路活着（**接手后第一时间做**）

### 2.2 RN App（手动）

1. 仅 JS 变更：Pushy 上传新版本 → 灰度/全量发布 → 🔲 具体命令/控制台步骤，向前任要一次演示
2. 原生变更：重新构建壳子（EAS 或本机 expo prebuild + gradle/xcode）→ 各商店/TestFlight 提交 → 🔲 完整步骤
3. 🔲 版本号规则（`app.config` / EAS 配置里的版本如何递增）

### 2.3 回滚

- Web：CD 自带（Node/Track 备份 dist/二进制 + health 失败自动恢复；静态站 .next 目录交换）
- 🔲 RN：Pushy 是否支持把用户切回旧 bundle（热更新回滚步骤）
