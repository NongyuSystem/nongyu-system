## 1. 背景

**Why**：实心白卡在浅底上看起来平；大屏 KPI 平铺，扫读没有「此刻 / 体量 / 趋势」层次；最高同时在线看不到发生时刻。  
**What**：在不拆贴边壳、不换品牌绿的前提下，把表面改成克制毛玻璃，重排大屏默认网格，并把峰值**首次达到**时刻画在今日 KPI 上。

**页面单一职责（不变）**：壳层负责导航与账号；页面负责本模块标题、主操作与数据。

---

## 2. 目标

1. 登录、壳层、工作台、数据大屏、CRUD `PageFrame` 使用同一套玻璃表面 token；助手**对话内部不改**。
2. 大屏默认布局按信息优先级重排（仅新用户与「恢复默认布局」；不 bump prefs version）。
3. `kpi-online-peak` 辅文为 `今日 HH:mm 达到`（`BUSINESS_TZ`）；未知时刻有明确空态，不编造。
4. BFF `GET /api/admin/track/overview` 透传 `onlinePeakAtMs`。同步 Node 契约文档。

---

## 3. 边界（非目标）

- 智慧助手面板内部：会话列表、消息气泡、输入条、工具卡片、设置表单。壳层打开按钮与抽屉外框可随玻璃 token 微调边框/背景，不重做对话交互。
- 深色模式、换主色、换字体、侧栏改成桌面中央悬浮岛、24px+ 圆角铺满。
- 趋势卡小时轴、每日峰值时刻 hover、回填历史时刻。
- 改采样周期、presence、RN 上报、dashboard prefs `version`（仍为 1）。
- 独立技术方案文档。
- 不改路由 path、菜单分组、接口鉴权。

## 5. 设计计划（frontend-design × MASTER）

**主体**：农屿管理台，给学院管理员日常办公。一页一件事：壳负责站稳，大屏负责「现在系统怎样」。

**材质名**：Greenhouse Frost（温室上的一层薄露）——青绿画布上的半透明白玻璃，不是营销大屏、不是 iOS 深色液态玻璃。

| 轴        | 选择                                                                                                                        |
| --------- | --------------------------------------------------------------------------------------------------------------------------- |
| Color     | 品牌 `#0A7C59` 只作按钮/选中点缀。画布雾灰 `#E6E9E7` + 极淡光斑，禁止饱和绿铺底、禁止绿描边箍白卡。玻璃填 `#FFFFFF` 40%–55% |
| Type      | 仍 Source Sans 3 + 苹方/雅黑。页标题 22–24 / 600；KPI 数字可略放到 32px；辅文 12–13 muted                                   |
| Layout    | **贴边**侧栏 + **fixed** 顶栏；卡片 12–16px 圆角。大屏默认：此刻 KPI 一行四卡（更宽），体量第二行                           |
| Signature | 侧栏选中绿条不变。本期唯一加码：画布光斑 + 玻璃描边（1px 浅白内高光 + 品牌线），让霜面可读                                  |

**不用**：奶油衬线、黑底酸绿、报纸细线、侧栏悬浮岛、强色散、全站 24px 圆角。

**玻璃可读性**：纯浅底上叠高不透明白等于看不见毛玻璃。画布用雾灰底 + **极淡**品牌光斑（`.ny-canvas-wash`），让霜面能折射但不把界面染绿；`backdrop-filter` saturate 约 1.2，忌 1.6+。内容卡填色约 40–55%、壳层 50–65%，`blur` ≥ 32px（窄屏可略降）。`prefers-reduced-transparency` / 不支持 `backdrop-filter` 时回退实心 `#FFFFFF`。

**霜面节点约束**：`backdrop-filter` 与 `overflow: hidden|auto`、自身 `transform` 不得同节点（WebKit / 部分 Chromium 会采成实心白）。滚动放内层；可点卡用 `.ny-glass-lift` 只加边与影。壳层用 `.ny-glass-chrome`，禁止玻璃套玻璃、hover 实心底。

```
桌面壳（贴边，不是悬浮岛）
+--------+----------------------------------------------+
| 霜面   | 霜面顶栏  农屿管理台         [助手] [账号]   |
| 侧栏   +----------------------------------------------+
| 绿条   | 页标题 22px                 [主操作]         |
|        | 霜面内容区（表格/表单）                      |
+--------+----------------------------------------------+

大屏默认 lg（12 列）扫读顺序
[当前在线][最高在线+时刻][今日日活][今日新增]   ← 此刻
[总用户          ][官网 PV         ]           ← 体量
[用户增长趋势 通栏]
[日活趋势     ][最高同时在线趋势 ]
[活跃排行 通栏]
[性别][年级][设备]  [学院 通栏]
[页面次数][页均停留]  [按钮点击 通栏]
[性能][Web Vitals]  [崩溃表 通栏]
```

## 6. 详细需求

### 6.1 MASTER / Token

同步修订 `design-system/web-admin/MASTER.md` 与 `tailwind.config.ts` / `index.css` / `antdTheme`：

| Token          | 用途                                                                                   |
| -------------- | -------------------------------------------------------------------------------------- |
| `canvas`       | 雾灰底 `#E6E9E7` + 极淡光斑（`.ny-canvas-wash`）；品牌绿不铺底                         |
| `surface`      | 内容卡霜面 `#FFFFFF` @ 40–55%；实心底回退 `#FFFFFF`                                    |
| `glass-chrome` | 贴边侧栏 / 顶栏 / 助手外框 `#FFFFFF` @ 50–65%，blur 略强于内容卡                       |
| `shadow-panel` | 内高光 + 极轻外漫射；不靠厚投影                                                        |
| 工具类         | `.ny-glass` / `.ny-glass-chrome` / `.ny-glass-lift`；禁止各页自写透明度或 hover 实心底 |

Ant Design `colorBgLayout` 对齐雾灰画布；`colorBgContainer` 在不支持透明时仍为白。表格头可略透，不把 Table 整表做成强模糊（可读性优先）。菜单选中底保持浅色点缀，不要大块 `#D4E9DF` 绿板。

顶栏、侧栏与内容卡同一套霜面；壳层加 `.ny-glass-chrome` 提高字对比，助手**仅外框**用玻璃，内栏不再套一层。

**窄屏（&lt; lg / 触控）**：光斑更淡、blur 可略降；lift hover 仅精细指针；输入 16px 防 iOS 缩放；顶栏用户名可收、操作 ≥44px；抽屉/助手 `100dvh` + safe-area；大屏禁拖拽（已有）。工作台引导文案按窄屏改「左上角菜单」，不写「侧栏」。

### 6.2 覆盖页面

| 表面                                    | 行为                                 |
| --------------------------------------- | ------------------------------------ |
| 登录卡                                  | 玻璃卡 + 画布渐变/光斑；表单逻辑不改 |
| `AdminShell` 侧栏、顶栏                 | 贴边霜面；选中绿条保留               |
| 工作台欢迎卡、入口卡                    | 玻璃；欢迎区左侧绿条保留             |
| `PageFrame` 默认内容壳                  | 玻璃替代实心白底                     |
| 大屏 `KpiCard` / `ChartCard` / 采样率条 | 玻璃；拖拽/缩放交互不改              |
| 相关网站入口卡、404                     | 玻璃                                 |
| 助手**内部**                            | 不改                                 |

### 6.3 大屏默认布局

文件：`dashboardLayout.ts` `DEFAULT_LAYOUTS`。

**优先级（上→下）**：此刻 → 体量 → 趋势 → 排行 → 用户是谁 → 行为 → 健康。

**lg（12 列）建议**：

| 行   | id                                                                                               | x,y,w,h                                   |
| ---- | ------------------------------------------------------------------------------------------------ | ----------------------------------------- |
| 此刻 | `kpi-online` `kpi-online-peak` `kpi-dau` `kpi-today-new`                                         | 各 w=3、h=2，y=0                          |
| 体量 | `kpi-total-users` `kpi-web-pv`                                                                   | 各 w=6、h=2，y=2                          |
| 趋势 | `chart-user-growth` 通栏；其下 `chart-dau-trend` \| `chart-online-peak-trend` 各 6               | 与现网高度一致                            |
| 其后 | 排行 → 性别/年级/设备 → 学院通栏 → 页面次数\|页均停留 → 按钮点击通栏 → 性能\|Web Vitals → 崩溃表 | 谁/行为分开，不再把学院和页面次数并成一行 |

**md / xs**：同一顺序；md 此刻两行（在线+峰值，日活+新增），体量一行两卡。

**Prefs**：`version` 仍为 1。已有 localStorage 布局不强制重置。新默认只作用于首次访问、损坏回退、「恢复默认布局」。

KPI 最低高度仍为 2 行；峰值时刻替换原辅文，不为此单独加高。若标题+数字+时刻三行溢出，优先收紧卡内 padding，不把全部 KPI 加到 h=3。

### 6.4 峰值时刻 UI

`TrackOverview` 增加：

```ts
onlinePeakAtMs: number | null; // UTC ms；未知 null
```

`kpi-online-peak`：

| 数据状态               | 辅文                                                                            |
| ---------------------- | ------------------------------------------------------------------------------- |
| 有 `onlinePeakAtMs`    | `今日 HH:mm 达到`（按 `BUSINESS_TZ` / 与大屏其它「今日」同一时区；仅时分，24h） |
| 峰值 > 0 但时刻 `null` | `峰值时刻未知`                                                                  |
| 峰值为 0 且时刻 `null` | `今日尚未形成峰值`                                                              |
| Track 失败             | 沿用现网错误文案，不展示假时刻                                                  |

- 原辅文「当日定时采样峰值」改为卡片 `title` 属性或 tooltip，避免挡住时刻。
- 禁止把 `updated_at` 或请求时间在「已有 stored 峰值且 live 未超过」时当成达到时刻。
- 趋势卡不展示时刻。

`KpiCard` 允许 `hint` 为时刻主辅文；可选 `hintTitle` 承载口径说明。不要为这一行新造第二种 KPI 组件。

### 6.5 BFF

`GET /api/admin/track/overview` 成功 `data` 增补：

```ts
onlinePeakAtMs: number | null; // Track online_peak_at_ms；缺省/非法 → null，禁止当 0
```

- `mapOverview` 映射 `online_peak_at_ms` → `onlinePeakAtMs`（仅 finite number 才采用）。
- 同步 `docs/nongyu-node-server/specs/管理端Track指标代理.md` 与 `接口文档概览.md` § track overview。
- 助手 SQL 提示词的 metric_key 列表可补 `online_peak_at_ms`（只读认知，不新工具）。

### 6.6 动效与无障碍

- `prefers-reduced-motion`：已有全局缩短，不新增入场动画堆。
- `prefers-reduced-transparency`：玻璃 → 实心 surface。
- 触控热区、对比度不低于现网正文。blur 不得导致表格字发糊（表格在玻璃容器内，单元格本身不 blur）。

## 7. 业务流程

```
管理员打开管理端任意页
  → 画布渐变 + 霜面壳 / PageFrame（助手内部除外）

打开 /dashboard
  → 读 prefs（旧布局则旧位；无则新默认）
  → track/overview 含 onlinePeak + onlinePeakAtMs
  → 峰值 KPI 画人数 + 时刻辅文

点「恢复默认布局」
  → 使用新 DEFAULT_LAYOUTS
```

## 8. 验收标准

1. 登录、工作台、用户/内容等 CRUD、大屏卡片均为同一玻璃材质；侧栏仍贴边，选中绿条仍在。
2. 助手对话区交互与信息结构与改前一致（允许外框 token 微调）。
3. 新用户或恢复默认后，大屏第一行是：当前在线、最高在线、日活、今日新增；总用户与官网 PV 在下一行。
4. 今日峰值有时刻时，KPI 可见 `今日 HH:mm 达到`，与采样首次升高一致（允许与 30s 任务相差一个间隔）。
5. 无时刻不编造；趋势图无时刻。
6. 降低系统透明度或旧内核无 blur 时，卡片仍实心可读。
7. `pnpm lint` / `type-check` / `format` 通过；Track / BFF / 管理端类型与接口文档已同步。

### 理想 UI

- 雾灰画布，卡片像一层薄霜，细白边；品牌绿只出现在按钮、选中条和少量点缀，不跟白卡对撞。
- 窄屏：顶栏不挤爆、输入不触发 iOS 缩放、点按无粘滞 hover；Home Indicator 不挡主操作。
- 峰值卡：大数字 + 一行时刻，口径藏在悬停说明里。
- CRUD 仍是「标题 / 主操作 / 工具栏 / 表」，只是容器换成霜面。
