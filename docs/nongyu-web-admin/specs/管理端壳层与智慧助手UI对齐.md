## 1. 背景

**Why**：管理端壳与智慧助手一期已上线，但左导航不可收起/拖宽，助手对话交互落后于 RN Agent（重试语义、停止态、生成中可输入等），桌面端效率与一致性不足；业务页停留时数据易过时。  
**What**：在不改问数工具与助手 Tabs 结构的前提下，对齐 RN Agent 对话壳层交互与视觉；左导航改为 fixed、可拖宽、可收起；助手抽屉可拖宽；偏好全局持久化；前台业务页每分钟静默刷新。

---

## 2. 目标

1. 桌面端左导航 `position: fixed`，主内容区按当前栏宽让位；滚动时左栏始终固定。
2. 左导航支持拖拽调宽与收起为图标栏；助手右侧抽屉支持拖拽调宽。
3. 展开/收起态与宽度写入全局 `localStorage`，刷新后恢复。
4. 智慧助手消息列表与输入交互对齐 RN：重试 / 重新生成、已停止、思考中、无气泡全宽、生成中可输入并「打断并发送」。
5. 小屏（&lt; lg）左栏保持现有抽屉，不引入桌面拖宽/收起。
6. 浏览器标签页可见时，当前业务页每 **60s** 静默刷新服务端数据，保证前台实时性。

---

## 3. 边界（非目标）

- 不改助手工具集、SQL/图表卡片业务逻辑与注册表。
- 不重构助手 Tabs（对话 / 会话 / 模型）信息架构。
- 不做 RN 式离页保活、后台生成。
- 不做收起快捷键；不在顶栏增加折叠按钮。
- 壳层偏好不按管理员账号分桶。
- 不修改 `nongyu-agent-sdk` 协议；仅复用现有 `useAgentChat` / `ChatMessage` 能力。若 SDK 缺能力导致无法对齐，另开切片。
- 本期不写独立 tech 文档。
- 不对登录页、工作台空态、版本管理 iframe、智慧助手对话做定时轮询。
- 不引入 WebSocket / SSE；不改后端推送协议。

## 5. 详细需求

### 5.1 左导航（桌面 ≥ lg）

- 容器：`position: fixed; left: 0; top: 0; bottom: 0; z-index` 低于顶栏浮层与助手抽屉，高于主画布。
- 宽度：
  - 展开：可拖，默认 `220`，范围 `[180, 360]`。
  - 收起：固定 `64`，不可拖宽；仅显示图标 + Tooltip 文案。
- 主内容区左侧偏移 = 当前左栏实际宽度；顶栏 `position: fixed`，桌面 `left` = 栏宽、主区 `padding-top` 让位，避免内容被遮挡。
- 折叠按钮：放在左栏内（品牌区旁或底部），点击在展开 ↔ 收起间切换；状态持久化。
- 拖动手柄：展开态右边缘；双击恢复默认 `220`。
- Brand / 菜单选中态仍遵循 MASTER（浅绿底 + 左侧品牌绿竖条）；收起态保留选中识别。

### 5.2 左导航（小屏 &lt; lg）

- 保持现有遮罩抽屉；汉堡打开 / 点遮罩或导航关闭。
- 不提供拖宽与图标栏收起。

### 5.3 智慧助手抽屉宽度

- 桌面：在现有 `useDrawerWidth` 基线上支持用户拖宽；默认 `420`，范围 `[320, 720]`；窄屏仍可全宽（现有 `useDrawerWidth` 行为优先于用户宽度）。
- 拖动手柄：抽屉左边缘（相对面板）；双击恢复默认 `420`。
- 用户宽度持久化；打开/关闭助手开关本身仍可不持久化（与一期一致）。

### 5.4 壳层偏好持久化

存储结构示例（实现可微调字段名，须版本前缀）：

```json
{
  "sidebarCollapsed": false,
  "sidebarWidth": 220,
  "assistantWidth": 420
}
```

- 非法 / 越界值：读入时 clamp 到合法范围；损坏 JSON 则回退默认。
- 登出：不清壳层偏好（与登录态无关）。

### 5.5 智慧助手对话壳层（对齐 RN）

在 `AssistantPanel` / `MessageList`（及相关输入区）落地，对照 RN `AssistantMessage` / `AiChatPanel` / `ChatEmptyState`：

| 行为       | 规格                                                          |
| ---------- | ------------------------------------------------------------- |
| 面板壳     | 自定义顶栏（关闭 / 会话 / 设置 / 新对话），非 Ant Tabs 主布局 |
| 空态       | 居中品牌标 + 问候 + 全宽建议条（对齐 RN ChatEmptyState）      |
| 输入条     | 圆角 Composer + 圆形发送/停止（对齐 RN composer）             |
| 重试       | 最近一条 assistant 为 `error` / `stopped` / 空回复 →「重试」  |
| 重新生成   | 最近一条正常 `done` →「重新生成」                             |
| 已停止     | Stop 后保留已生成正文，展示「已停止」                         |
| 思考中     | streaming/pending 且尚无正文、无 tool 时显示思考中指示        |
| 排版       | assistant 无气泡全宽；流式纯文本，完成后 Markdown             |
| 用户气泡   | 右对齐品牌色气泡，大圆角 + 右下小圆角                         |
| 生成中输入 | 对齐 RN：生成中禁用输入，仅 Stop；结束后再发                  |
| 操作入口   | 仅最近一条 assistant 下方；生成中不显示操作条                 |

非目标复述：不改工具 chip/卡片渲染逻辑。

### 5.6 前台静默刷新（60s）

#### 前台定义

- 以 `document.visibilityState === "visible"` 为前台。
- 标签页 hidden：停止定时器，不发请求。
- 从 hidden → visible：立即补刷一次当前页，并重启 60s 周期。

#### 覆盖范围（须接入）

| 页面 / 区域            | 刷新内容                                                       |
| ---------------------- | -------------------------------------------------------------- |
| 数据大屏               | 核心指标 + 埋点指标（沿用当前筛选：growthRange、crashPage）    |
| 用户管理               | 当前列表查询条件结果                                           |
| 内容管理               | 当前帖子列表（及若详情 Drawer 打开时的详情，可选；默认仅列表） |
| 首页问候               | 列表                                                           |
| AI 建议                | 列表                                                           |
| LLM Key 池             | 列表                                                           |
| 埋点失败等已有列表面板 | 列表                                                           |

#### 明确不覆盖

- 登录页、工作台空态、版本管理（Pushy iframe）、智慧助手对话/会话/模型设置。

#### 行为约束

- 间隔：**60_000 ms**。
- **静默**：不触发整页/首屏 Loading 闪烁；失败不强制 Toast（可弱提示或不提示）。
- **编辑保护**：页面存在打开的 Modal / 表单 Drawer 且用户可能在编辑时，该次轮询**跳过**（由页面传入 `enabled` 或 `shouldSkip`）。
- 实现形态：通用 hook `useForegroundRefresh(callback, { intervalMs: 60_000, enabled })`；各页注册自身静默 `load*`（可用 `useEffectEvent` 保持最新闭包）。
- 仅刷新**当前路由已挂载**的页面；切走路由后旧页卸载即停。

### 5.7 视觉与设计准则

- 壳层：贴边、轻分割线、品牌绿选中，遵循 `design-system/web-admin/MASTER.md`。
- 拖拽热区 hover 可有细线高亮，忌厚重把手/发光。
- 对话区对齐 RN 层级：次要操作文案用 secondary 色，错误用 danger。

## 6. 业务流程

### 6.1 调宽左栏

1. 用户在展开态按住右缘拖动 → 实时改宽并让位主区 → 松手写入 localStorage。
2. 双击手柄 → 宽度恢复 220 并持久化。

### 6.2 收起 / 展开

1. 点折叠按钮 → 切到 64px 图标栏（或从收起恢复上次展开宽度）→ 持久化 `sidebarCollapsed`。
2. 收起态不可拖宽；展开后恢复可拖。

### 6.3 助手拖宽

1. 助手打开时，拖左缘调宽 → clamp → 持久化。
2. 双击 → 恢复 420。

### 6.4 重试 / 重新生成 / 打断发送

与 RN `农屿Agent交互优化` 同语义；实现上优先复用 `useAgentChat` 的 `reload` / `stop` / `append`（或等价 API）。若现有 hook 在 Web 上无法区分「重试 vs 重新生成」文案，允许在 UI 层按 `message.status` 分支，底层仍走同一 regenerate/reload 路径。

### 6.5 前台静默刷新

1. 进入业务页且标签可见 → 启动 60s 定时器。
2. 到期 → 若未在编辑保护态 → 静默拉取并更新状态。
3. 标签 hidden → 清定时器；再可见 → 立即补刷 + 重启定时器。
4. 离开路由 → 卸载清理。

## 7. 验收标准与测试方案

### 7.1 左栏

| #   | 场景         | 期望                            |
| --- | ------------ | ------------------------------- |
| 1   | 桌面滚动长页 | 左栏始终贴左固定，不随内容滚走  |
| 2   | 拖宽至边界外 | clamp 到 180–360                |
| 3   | 收起         | 宽约 64，仅图标；主区让位同步   |
| 4   | 刷新         | 宽度与收起态恢复                |
| 5   | 双击手柄     | 回到 220                        |
| 6   | 窄屏         | 仍为汉堡抽屉；无桌面拖宽/图标栏 |

### 7.2 助手宽度

| #   | 场景     | 期望                       |
| --- | -------- | -------------------------- |
| 1   | 拖宽     | clamp 320–720，刷新保留    |
| 2   | 双击     | 回到 420                   |
| 3   | 极窄视口 | 仍可全宽展示（响应式优先） |

### 7.3 对话交互

| #   | 场景             | 期望                                |
| --- | ---------------- | ----------------------------------- |
| 1   | 生成失败         | 显示错误 +「重试」；点后不新增 user |
| 2   | 用户停止         | 「已停止」+「重试」；正文保留       |
| 3   | 空回复           | 「重试」                            |
| 4   | 正常完成         | 「重新生成」                        |
| 5   | 生成中输入并发送 | 先停再发新问题                      |
| 6   | 流式开始         | 「思考中」；无气泡全宽排版          |
| 7   | 工具卡片         | 行为与一期一致                      |

### 7.4 前台静默刷新

| #   | 场景                            | 期望                              |
| --- | ------------------------------- | --------------------------------- |
| 1   | 大屏前台停留 ≥1 分钟            | 指标静默更新，无整页 Loading 闪烁 |
| 2   | 标签切到后台                    | 不再发轮询请求                    |
| 3   | 标签切回前台                    | 立即补刷一次                      |
| 4   | 打开新建/编辑 Modal             | 轮询跳过，表单不被冲掉            |
| 5   | 登录 / 工作台 / 版本管理 / 助手 | 无 60s 业务轮询                   |

### 7.5 回归

- 登录 / 登出 / 改密入口正常。
- 助手会话列表、模型设置、问数工具结果卡片可用。
- 菜单路由跳转与选中态正确（含收起态）。
