## 1. 实施计划

一人交付。先打通峰值时刻数据链（Track → BFF → KPI），再铺全站霜面与大屏默认网格。

| 步骤 | 内容                                                                       | 风险                       |
| ---- | -------------------------------------------------------------------------- | -------------------------- |
| 1    | Go / Node `BumpPeak` 首次达到写入 `online_peak_at_ms`；overview 透出；单测 | 双实现漂移：两处同一规则   |
| 2    | BFF `mapOverview` → `onlinePeakAtMs`；同步接口文档与 Track 代理 Spec       | 缺字段当 0                 |
| 3    | 管理端 `ny-glass` + 画布；壳 / 登录 / PageFrame / 大屏卡 / 工作台          | 白叠白看不见玻璃           |
| 4    | 默认 `DEFAULT_LAYOUTS` 重排；峰值 KPI 时刻辅文                             | 旧 localStorage 不强制重置 |
| 5    | lint / type-check / format；Track 单测；浏览器走登录与大屏                 |                            |

**不改**：助手对话内部、prefs version、趋势按小时、采样周期。

---

## 2. 实施步骤

### 2.1 Track

- Go `BumpPeak`、Node `bumpPeak`：仅峰值严格升高时写 `online_peak_at_ms`。
- Overview 今日：`max(stored, live)`；live 更高则时刻用请求 now，不在 GET 写库。
- 历史日：有则数字，无则 JSON `null`。

### 2.2 BFF / 管理端数据

- `online_peak_at_ms` → `onlinePeakAtMs: number \| null`。
- KPI：`今日 HH:mm 达到` / `峰值时刻未知` / `今日尚未形成峰值`。

### 2.3 UI

- `index.css`：`.ny-canvas-wash` 雾灰 + 极淡光斑；`.ny-glass` 薄填 + 强 blur、**低 saturate**、无绿描边；壳层 `.ny-glass-chrome`；lift hover 仅精细指针。
- 窄屏：输入 16px、`.ny-hit` 44px、顶栏收用户名、工作台文案、登录去掉高饱和光球。
- **霜面节点禁止** `overflow` / 自身 `transform`；`PageFrame` 滚动放内层；助手内栏不再套玻璃。
- 统一替换实心白卡；侧栏仍贴边。
- `DEFAULT_LAYOUTS` 按 Spec §6.3。
